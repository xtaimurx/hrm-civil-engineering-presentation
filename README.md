# HRM in Civil Engineering · v7 (Dusk Ascent)

Open `index.html` in Chrome or Edge, straight from the folder. No server and no internet needed.
Press `F` for fullscreen.

| Key | Action |
| --- | --- |
| → / Space / PageDown / left click | Next |
| ← / PageUp / right click | Back |
| Home / End | First / last state |
| H | Hide floor counter and state counter |
| F | Fullscreen |
| `#n` in the URL | Jump to state n (for example `index.html#19`) |

32 states, same order and copy as v5 (`scenes.js` is copied unchanged; `extras.js` holds text that v5 kept in its slide templates).

| States | Section |
| --- | --- |
| 1–2 | Hook question and the record |
| 3–6 | Why it matters, what HRM is |
| 7–18 | Functions, planning, life cycle, performance, productivity |
| 19–30 | Challenges, safety, Pakistan, recommendations, conclusion |
| 31 | Questions and discussion |
| 32 | Overview of the whole tower |

Performance: there is no world-sized layer. Only the tower photo and one or two panels are ever on screen and moving. Photos are pre-toned, so there are no CSS filters. All images are decoded before the first slide shows.
